# Sunsoari – thème « Sunsoari - fullstack »

- `remote/` : copie des fichiers du thème avant modification (référence).
- `build/` : générateur Python (`products.py`, `pages.py`, `settings.py`).
- `theme/` : fichiers générés, envoyés dans le thème non publié « Sunsoari - fullstack ».

Regénérer : `cd build && python3 products.py && python3 pages.py && python3 settings.py`.

## Fiches produit (v2)

Les modèles portent les noms déjà attribués aux produits : ils s'affichent
dans l'aperçu du thème sans rien changer sur le site en ligne.
Voir `build/v2.py` (LIVE_NAMES) pour la correspondance.

Régénérer : `cd build && python3 v2.py`.
